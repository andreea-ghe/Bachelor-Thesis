\chapter{Theoretical Background}
\label{chap:ch3}

This chapter presents the theoretical foundations underlying the proposed approach: point cloud representations and their structural properties, deep learning architectures for point sets (PointNet, PointNet++), transformer-based attention mechanisms, and the RANSAC algorithm for robust rigid transformation estimation.

\section{Point Cloud Representation}

A common representation for 3D geometry in learning-based pipelines is the point cloud, usually chosen due to their simplicity and flexibility. A point cloud is an unstructured set of 3D points, where each point \(p_i\) may include additional attributes such as color or surface normals. Unlike volumetric voxel grids, which suffer from cubic memory costs and resolution limits, or 3D meshes, which introduce complex and irregular topological connectivity, point clouds provide a highly efficient raw geometric representation. However, effectively processing these raw spatial data requires neural network architectures to explicitly account for three intrinsic structural properties:
\begin{itemize}
    \item \textbf{Permutation invariance;} Because point clouds lack a rigid spatial grid, the physical shape they represent remains identical regardless of how the points are ordered in memory. Consequently, any model processing them must be permutation invariant, ensuring it produces the exact same output regardless of the input data sequence.
    \item \textbf{Local geometric structure;} A single isolated point provides no meaningful contextual information. Identifiable geometric features, such as fracture edges, corners, or smooth surfaces, emerge only from the spatial proximity and interaction between neighboring points. Models must therefore be capable of grouping points to capture these localized structures.
    \item \textbf{Rigid transformation invariance;} The intrinsic geometry of an object does not change based on its location or orientation. Therefore, the learned representations must remain consistent under global rigid transformations, such as 3D translations and rotations in space.
\end{itemize}

Because of these unique properties, standard Convolutional Neural Networks are fundamentally ill-equipped to process point clouds directly (Figure~\ref{fig:3d_representations}). Classical convolutions are strictly based on the fixed spatial order and uniform density of regular grids. Since point clouds are unordered sets scattered continuously in 3D space, traditional convolutional operations cannot be applied, necessitating the use of specialized, order-agnostic architectures.

\section{PointNet and PointNet++}
\label{sec:pointnet}

To address the inherent challenges of processing unstructured 3D data, early research introduced architectures designed specifically for point sets, like PointNet \cite{qi2017pointnet}. Instead of aggregating information from local neighbors using a spatial kernel and extracting a feature from a local patch of pixels, PointNet learns features for each point independently. It replaces the convolutional kernel with a shared Multi-Layer Perceptron (MLP), denoted \(h:\mathbf{R}^3 \xrightarrow{} \mathbf{R}^K\), which acts as a pointwise feature extractor. For every individual point \(x_i\), the network computes a high-dimensional feature vector \(h(x_i)\). 

Because these features are extracted independently, a permutation-invariant aggregation is needed to capture global structure. PointNet achieves this through global max pooling:
\begin{equation}
\label{eq:pointnet_pool}
g=\max_{i=1 \ldots n}h(x_i)
\end{equation}
Because \(\max\) is a symmetric function, the output is invariant to input ordering. While CNNs build global understanding by progressively combining localized structures, PointNet aggregates the most dominant pointwise responses directly (Figure~\ref{fig:pointnet}).

    \caption{The PointNet architecture \cite{qi2017pointnet}. Each point is independently transformed by a shared MLP, and a symmetric max-pooling operation aggregates the per-point features into a single global descriptor.}
    \label{fig:pointnet}
\end{figure}

While the foundational PointNet formulation successfully guarantees permutation invariance through global max-pooling, it introduces a critical limitation: by design, it does not capture the local structures such as spatial distances and geometric interactions. To overcome this lack of local shape awareness, PointNet++ \cite{qi2017pointnetplusplus} introduces a hierarchical architecture that applies PointNet recursively on a nested partitioning of the input point set. By exploiting the underlying metric space, this hierarchy allows the network to capture fine-grained local features at continuously increasing contextual scales, analogous to the progressively larger receptive fields found in CNNs.

This hierarchical feature learning is achieved through an encoder made of repeated Set Abstraction levels. Each Set Abstraction level progressively downsamples the point cloud by using Farthest Point Sampling \cite{qi2017pointnetplusplus} to select a sparse set of centroids, groups neighboring points within a fixed metric radius, and applies a miniature PointNet to encode these localized regions into highly descriptive feature vectors. Because real-world point clouds often suffer from non-uniform sampling densities, PointNet++ also employs density-adaptive strategies, such as Multi-Scale Grouping, which intelligently combine features extracted from neighborhoods of varying sizes to ensure robustness (Figure~\ref{fig:pointnet++}).

\section{Transformers and Attention Mechanisms}

Although PointNet++ captures local geometric structures through hierarchical neighborhoods, max-pooling discards the relationships between points within each region. For tasks such as fracture boundary matching, the network must understand how different points relate to one another, not just which features are most prominent. Modern architectures address this by replacing max-pooling with the Attention mechanism \cite{vaswani2017attention}, the core component of Transformer networks.

Originally designed for natural language processing, transformers have proven effective for 3D point cloud processing. The self-attention operator at their core is a set operator: it computes relationships by comparing elements against one another rather than relying on a fixed grid or sequential order, making it invariant to both the permutation and cardinality of the input. This makes the transformer well suited for processing unordered point clouds.

At its core, the attention mechanism maps a Query and a set of Key-Value pairs to an output representation. Each point's features are linearly projected into a Query vector (encoding what the point is searching for), a Key vector (encoding its structural identity), and a Value vector (carrying its feature content). The network computes dot products between Queries and Keys to measure pairwise compatibility; these scores are normalized via softmax to produce attention weights that determine how much each point's Value contributes to the output. Unlike the hard selection of max pooling, attention computes a dynamically weighted sum based on structural context.

In the context of 3D fractured object reassembly, architectures like Jigsaw \cite{lu2023jigsaw} utilize two distinct variations of this mechanism to establish geometric matches:

\paragraph{Self-Attention.} In this layer, the Queries, Keys, and Values all come from the same point cloud. The network relates different positions within a single fractured piece to build a highly refined understanding of its own internal geometry and structural context.

\paragraph{Cross-Attention.} Once the internal geometry is understood, the network must find how two different pieces fit together. In cross-attention, the Queries come from the feature representations of Fragment A, while the Keys and Values come from Fragment B. This allows the points on one fractured surface to explicitly search the geometry of the other piece, facilitating the communication of local features across different fragments to find the exact point-to-point correspondences required for assembly.

\section{RANSAC}

The Random Sample Consensus (RANSAC) \cite{fischler1981random} algorithm is a robust mathematical estimation paradigm introduced by Fischler and Bolles. Rather than utilizing the entire dataset to compute an initial model and subsequently filtering out errors, RANSAC takes the opposite approach: it uses the smallest feasible subset of data to instantiate a model hypothesis, and then evaluates how much of the remaining data consistently aligns with that model.

\sloppy
Formally, given a dataset \(P\) and a model requiring \(n\) points to instantiate, RANSAC randomly selects a subset of n points to generate a hypothesis model, \(M1\). This model is then tested against all remaining points in P. Points that fall within a predefined error tolerance of M1 are classified as "inliers" and form the consensus set. If the size of this consensus set exceeds a specific threshold t, the model is accepted, and a refined model is typically recomputed using all identified inliers. If the consensus set is too small, the algorithm randomly samples a new subset of n points and repeats the process. After a predetermined number of iterations, the transformation that produced the largest consensus set is selected as the final solution.

The Jigsaw framework adopts this exact methodology to filter out false point-to-point correspondences predicted between fracture surfaces. Because neural networks inevitably predict some erroneous matches (outliers) that would severely degrade a global pose estimation, RANSAC is used to isolate the reliable geometric matches. In SE(3) space, the minimum number of points required to determine a rigid transformation is 3. Therefore, RANSAC randomly samples 3 corresponding point pairs from the two fragments.

To compute the transformation hypothesis from these 3 pairs, the algorithm solves the orthogonal Procrustes problem via Singular Value Decomposition (SVD) \cite{golub2013matrix}: the points are centered, the cross-covariance matrix is decomposed, and the optimal rotation is extracted while the translation is recovered from the centroid offset. The full SVD-based derivation is presented in Chapter~\ref{chap:ch5} (Equation~\ref{eq:procrustes}), where it is also used for differentiable pose estimation during training.
% To compute the transformation hypothesis from these 3 pairs, the algorithm utilizes Singular Value Decomposition (SVD) \cite{golub2013matrix}. First, the points from both fragments are centered at the origin by subtracting their respective centroids. These centered points are assembled into coordinate matrices \(A\) and \(B\). To find the optimal rotation matrix R that minimizes the least-squares error \(\lVert AR-B \rVert\), the algorithm computes the cross-covariance matrix \(H=A^TB\) and decomposes it via SVD such that \(H=U \sum V^T\). Because physical fragments must undergo a rigid transformation without any scaling or stretching, the singular values matrix \(\sum\) is discarded, and the pure rotation is extracted as \(R=UV^T\). The translation vector is then easily calculated by measuring the offset between the two original centroids after the rotation is applied.

Once this candidate transformation is calculated, it is applied to all other matched points to determine the consensus set. By repeating this hypothesis-and-evaluation loop, RANSAC successfully discards the hallucinated matches and outputs a highly reliable pairwise transformation based purely on the geometric inliers.
