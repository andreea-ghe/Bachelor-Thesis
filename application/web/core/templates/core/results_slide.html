Key Findings

  • Gated double attention: consistent cross-domain gains (+2.6 pp PA on artifact), acts as implicit regularizer
  • Gabriel filtering: higher-quality matches, reduces chamfer distance on artifact by ~10%
  • ICP refinement: stable +1 pp chamfer improvement across all configurations
  • Pair attention: acts as learned soft regularizer; improves OOD generalization on two-piece, but less clear on multi-piece
  • Data quantity is the dominant factor, but architecture and data address the same gap from complementary directions
