Jigsaw Pipeline

The model processes fracture pieces through four stages, from raw point clouds to globally consistent poses.

Feature Extraction

PointNet++ encodes local geometry at multiple scales. Self-attention refines per-point features using k-NN neighborhoods with positional encodings from 3D distances.

Cross-Attention

Multi-head attention between fragments establishes inter-piece correspondences, bridging the geometric gap across fracture surfaces.

Primal-Dual Matching

Features split into primal (convex) and dual (concave) spaces. Sinkhorn optimal transport produces soft assignments; Hungarian algorithm extracts discrete one-to-one matches.

Global Alignment

RANSAC estimates pairwise rigid transforms from correspondences. ICP refines locally. Shonan averaging jointly optimizes all poses for global cycle consistency.
