Feature Extraction

PointNet++ encodes local geometry at multiple scales using Set Abstraction layers with kNN grouping, shared MLPs, and max-pooling over local neighborhoods.

Attention Layers

Self-attention captures relationships between points within each fragment. Cross-attention lets all points from all fragments attend to each other, enabling matching of fracture surfaces.

Primal-Dual Matching

Features split into primal (convex) and dual (concave) descriptors. Sinkhorn optimal transport produces soft assignments; the Hungarian algorithm extracts discrete one-to-one matches.

Global Alignment

RANSAC estimates pairwise rigid transforms from correspondences. ICP refines locally. Shonan averaging jointly optimizes all poses for global cycle consistency.
