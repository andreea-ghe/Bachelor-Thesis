{# Slide 3: Key improvements to the architecture #}

Proposed Improvements

Pair Geometric Attention

Standard cross-attention relies on learned feature similarity alone. When fragments multiply, matching becomes expensive and ambiguous.

We inject a learnable scalar bias bij into attention logits, derived from inter-centroid Gaussian RBF distances and triplet angle descriptors, aggregated through a small MLP.

Designed primarily for ≥3 pieces. For two fragments, the bias reduces to a single scalar and triplet angles are undefined.

Gated Double Attention

The baseline runs one self-attention + one cross-attention pass before matching. We add a second pass of both, controlled by zero-initialized gates (ReZero): output = first-pass features + g · residual.

At init, gates are zero — the model is identical to the pretrained baseline. Capacity activates only when training finds it useful. Empirically, the cross-attention gate goes negative, subtracting first-pass inter-fragment patterns rather than purely adding.
